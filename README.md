# EasyNote 产品说明

欢迎使用 **EasyNote** —— 一款简洁高效的多平台笔记应用，助您随时随地记录、整理和查找灵感与信息。

---

## 产品简介

**EasyNote** 专为追求高效与便捷的用户设计，聚焦"极简操作、强大编辑、数据安全"三大核心理念。无论是工作笔记、学习摘录，还是生活随记，EasyNote 都能为您提供流畅的笔记管理体验。

---

## 主要功能

- **多平台支持**  
  兼容主流桌面操作系统，随时随地访问您的笔记。

- **富文本编辑**  
  支持标题、列表、加粗、斜体、插入图片等多种排版格式，记录更灵活。

- **本地数据存储**  
  所有笔记默认保存在本地，无需担心隐私泄露，断网亦可访问。

- **快捷新建与查找**  
  一键新建笔记，支持关键词快速搜索，定位所需内容。

- **自动保存与版本管理**  
  编辑内容实时保存，减少数据丢失风险。

- **轻量级启动**  
  启动迅速、占用资源低，适合长期后台运行。

## 安装方法

### 系统要求

- Windows 10 及以上 / macOS 11 及以上 / 主流 Linux 发行版
- 推荐内存 ≥ 2GB

### 安装步骤

1. [下载最新版 EasyNote 安装包](#)（请根据操作系统选择对应版本）。
2. 按照安装向导完成安装。
3. 安装完成后，双击桌面图标或在开始菜单/应用程序中搜索"EasyNote"启动应用。

> **首次启动说明**  
> 无需注册账号，直接进入主界面即可新建和管理笔记。

---

## 基本使用方法

- **新建笔记**  
  点击主界面"新建"按钮，输入标题与内容，编辑完成后自动保存。

- **编辑与格式化**  
  在编辑区可使用工具栏进行加粗、斜体、插入图片、创建列表等操作。

- **保存与同步**  
  笔记内容自动实时保存，无需手动操作。如支持云端功能时可在设置中开启数据同步。

- **查找与管理**  
  在搜索框输入关键词，快速定位目标笔记。支持按时间、标题等排序。

## 常见问题

**Q1：我的笔记数据存储在哪里？**  
A1：所有笔记默认保存在本地设备的专用数据目录，无需联网即可访问和编辑。

**Q2：使用 EasyNote 需要注册账号吗？**  
A2：无需注册即可本地使用全部核心功能。如需云同步功能，后续可选择注册账户。

**Q3：数据是否支持导出/备份？**  
A3：支持将笔记导出为 Markdown 或文本格式，便于备份和迁移。

**Q4：如何恢复误删的笔记？**  
A4：部分版本支持回收站功能，删除的笔记可在回收站中找回。
